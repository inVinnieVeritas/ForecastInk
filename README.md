# KindleDash 1.0.0-beta.45

Top-panel rebalance based on beta.44 hardware feedback.

Changes:
- Brussels moved lower and reduced slightly to stop clipping into the top panel border
- current hour repositioned for matching top padding
- main weather icon slightly enlarged and centered in the left half
- current temperature widened across more of the right half
- condition, feels-like, and high/low enlarged and widened
- sunrise/sunset kept inside the left half
- hourly temperatures lifted above the lower forecast-panel border

Weather parsing, night/day logic, battery logic, RTC wake, and top-of-hour refresh are unchanged.
